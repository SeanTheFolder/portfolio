01 / Current focus

On the bench

Active
HITRUST CSF readiness build at Harbors. Building forward from the existing CIS v8 program. The architecture was designed for HITRUST from day one; the current phase is gap analysis against r2 control requirements, evidence collection, and selecting an external assessor.
Active
Multi-LLM evaluation cycle for healthcare. Re-running the eval suite against current Claude, Gemini, GPT, Antigravity, and Copilot releases. Per-task model selection holds up. The interesting shifts are in long-context reasoning over clinical documentation and adversarial robustness on prompt injection.
Active
Paperclip open-source releases. Cleaning up the multi-agent simulation for an external release with reproducible scenarios, and adding governance hook points so others can run safety experiments without rewriting the scheduler. Looking for collaborators with multi-agent systems backgrounds.
Planning
OCR HIPAA audit preparation. OCR’s third HIPAA audit phase is underway and targets risk analysis specifically. Refreshing the risk analysis methodology and evidence binders so an audit notice is a confirmation event, not a scramble.
Learning
Antigravity for team development workflows. Evaluating Google Antigravity as a complement to Claude Code for team-based development: developer ergonomics, output quality, and governance surface area against current Claude Code workflows.
