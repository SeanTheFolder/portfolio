CIS Controls v8: Full Compliance Program from Zero

Built the organization's compliance program from nothing. A full CIS Controls v8 implementation across all 18 domains, crosswalked to the HIPAA Security Rule, audited at 100% pass, and architected for HITRUST CSF readiness.

Date
June 2025
Duration
6 months
Scope
Enterprise
Status
Completed

01 / The problem

There was no compliance program. No documented controls, no crosswalk to HIPAA, no audit posture. The organization was operating in a HIPAA-regulated environment with no framework mapping the regulatory obligations to actual technical and administrative controls.

02 / The approach

  1. Mapped every CIS Controls v8 safeguard to the corresponding HIPAA Security Rule citation, producing a single crosswalk document leadership and auditors could both read
  2. Implemented controls domain-by-domain over six months, sequencing by risk reduction per dollar. Inventory and access management came first, then more advanced detection
  3. Deployed CIS-CAT Pro for continuous configuration assessment so posture drift surfaces between audits, not at them
  4. Built a monthly board-level posture dashboard tracking control maturity, gaps, and remediation timelines in business terms
  5. Engaged third-party penetration testing against the matured program. Passed on the first attempt
  6. Architected the entire program for forward compatibility with HITRUST CSF certification, even though formal certification is a later milestone

04 / What I learned

Compliance programs fail when they're run as documentation projects instead of engineering projects. Every control needs to map to a real technical or procedural artifact you can point to in an audit, not a paragraph in a binder. The crosswalk between CIS v8 and the HIPAA Security Rule was the single most useful document I built. Auditors and leadership both read it differently and both find what they need. Build the crosswalk first, then build the controls.
