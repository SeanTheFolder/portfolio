Greenfield IT Buildout for Creative Studio

Stood up a complete IT environment for a creative studio moving into a new space. Network, server, storage, identity, workstations, AV, and physical security from an empty room to a working studio in twelve weeks. No legacy debt to inherit, which was the point.

Date
August 2019
Duration
12 weeks
Scope
Client Engagement
Status
Completed

01 / The problem

The client had outgrown a coworking space and was opening a dedicated studio. They had no internal IT, no domain, no central file storage, no managed wireless, and had been working off personal Dropbox accounts and consumer routers. They needed everything at once and they needed it to work on day one.

02 / The approach

  1. Designed the network for creative workflow realities: high-throughput LAN for large file movement between workstations and storage, fast wireless for client meetings, and segmented guest WiFi for visitors
  2. Specified a NAS-based central file storage tier with daily snapshots and weekly off-site backup to satisfy both creative collaboration and recovery needs
  3. Stood up Microsoft 365 with Entra ID identity, mailbox migration, and SharePoint for non-creative documents. Conditional Access from day one rather than as a bolt-on later
  4. Imaged and deployed workstations from a standard build with creative software pre-installed and configured. Documented the build process so future hardware refreshes are repeatable
  5. Specified and installed conference room AV including video conferencing and presentation tooling, integrated with the rest of the M365 environment
  6. Installed a small access control system at the entrance, integrated with identity, with audit logging from day one

04 / What I learned

Greenfield IT projects are gifts. You only get them when the alternative is worse, and they are the rare opportunity to build the right thing the first time. Resist the temptation to copy the architecture you would have inherited. Identity-first design from day one, with Conditional Access and audit logging in place before the first workstation is deployed, is dramatically easier than retrofitting later. Also: document the standard build during the build, not after. The notes you make while doing it the first time become the runbook for every subsequent hire.
