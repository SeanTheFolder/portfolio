Departmental Self-Serve Operations Dashboards

Built a self-serve operations dashboard for every functional department, sourced from the same warehouse that feeds the executive view. Department heads stopped emailing IT for ad-hoc reports and started running their own weekly operating reviews against the same numbers leadership is reading. Decentralized analytics without losing definitional control.

Date
March 2026
Duration
Rolled out across departments over 14 weeks
Scope
Department
Status
Ongoing

01 / The problem

Department heads were running their teams off Excel files exported from various systems, each filtered and transformed manually each week. Two managers reading the same source data routinely arrived at different conclusions. IT was a permanent bottleneck for ad-hoc reporting requests, and the requests themselves were rarely the right question phrased the right way. The organization had data and no operational analytics culture.

02 / The approach

  1. Started with a single pilot department (clinical operations) to prove the model before expanding
  2. Built a shared semantic layer in Microsoft Fabric so that every dashboard pulls from the same governed dataset with the same definitions used by the executive dashboard
  3. Defined a per-department template with four standard panels (Demand, Throughput, Quality, People) and one customization slot the department owns
  4. Sat with each department head for two sessions: one to map their actual weekly operating questions, one to walk through the dashboard before launch and adjust the customization slot
  5. Trained each department head on filtering, drill-down, and how to bookmark a personal view rather than asking IT to build one
  6. Wired in a feedback button on every dashboard so requests for changes go straight to a JSM queue tagged by department
  7. Established a quarterly dashboard review with each department head to retire stale measures and add ones the team has earned the right to track

04 / What I learned

Self-serve only works when the underlying definitions are non-negotiable. Letting department heads invent their own measures recreates the original problem at a higher resolution. The right model is: shared definitions and a shared dataset, freedom in how each leader views and slices it. The customization slot was the unlock. Without it, every department head felt the dashboard was imposed on them. With it, the dashboard belongs to them.
