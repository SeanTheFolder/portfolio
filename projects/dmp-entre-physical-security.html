DMP Entré Access Control & Ubiquiti Camera Systems

Built enterprise physical security from zero. DMP Entré access control across all facilities and Ubiquiti UniFi camera coverage at every entry point. Physical and logical access events now flow into the same audit trail under unified identity.

Date
April 2025
Duration
14 weeks
Scope
Infrastructure
Status
Completed

01 / The problem

Physical security was traditional locks and a handful of standalone cameras with no central management. There was no audit trail for facility access, no integration with identity, and no way to correlate a badge event with a logical sign-in. For a HIPAA-regulated facility, that's a control gap with explicit citations attached to it.

02 / The approach

  1. Surveyed every facility for door types, camera placement requirements, and the existing electrical and network paths to support new infrastructure
  2. Specified DMP Entré access control with credentials and readers at every clinical, admin, and restricted-area door
  3. Deployed Ubiquiti UniFi Protect cameras at exterior entries, interior corridors, and any area covered by HIPAA facility access controls
  4. Integrated DMP Entré with Entra ID so badge provisioning and deprovisioning track identity lifecycle. A termination revokes physical access automatically
  5. Routed access events into the same audit log pipeline as logical access events so investigations have one timeline

04 / What I learned

The interesting work in physical security isn't the hardware. It's the identity integration. A badge system that doesn't auto-revoke when HR offboards is just a slower version of the locked-out-the-back-door problem. Wire the lifecycle integration on day one, not as a follow-up. Also: cameras get specified by coverage, but the operational question is retention. Pick retention windows that satisfy regulatory requirements without drowning in storage costs, and document the decision because someone will ask.
