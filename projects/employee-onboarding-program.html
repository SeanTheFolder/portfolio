Employee Onboarding Program from Scratch

Built the organization's first structured onboarding program. Fully automated endpoint provisioning via Autopilot, day-one security awareness training, and identity lifecycle management through Entra ID. New hires are productive and compliant before IT lifts a finger.

October 2024

The Problem

Onboarding was ad-hoc. Every new hire kicked off a series of email threads to provision systems, image a laptop, schedule training, and grant access. Often days or weeks late. There was no day-one experience, no structured security awareness, and no identity lifecycle to speak of.

Approach

  1. Designed a hire-to-active workflow triggered by an HR start-date event in ADP that flows through Entra ID provisioning
  2. Configured Autopilot deployment profiles per role so the laptop ships pre-enrolled, pre-configured, and waiting for the user's first sign-in
  3. Mandated security awareness training as a Conditional Access prerequisite. No training, no sign-in to organization resources
  4. Built a SharePoint intranet onboarding hub with policies, runbooks, and the org chart so day-one questions answer themselves
  5. Tied offboarding to the same lifecycle. Termination in HR triggers immediate revocation of identity, device, badge, and licensed application access

Lessons Learned

Onboarding programs are easier to design than to maintain. The workflow degrades the moment HR adds a new role or IT changes a deployment profile and nobody updates the linkage. Build a quarterly review into the cadence so the workflow stays in sync with how the organization actually staffs and provisions. Also: making security awareness a Conditional Access gate sounds aggressive, but it works. Users complete training the first day instead of dragging it out for weeks.
