SaaS License & Vendor Spend Rationalization Program

Ran a structured audit of every SaaS subscription, recurring software license, and IT vendor contract across the organization. Cut annual spend by a meaningful percentage, decommissioned a long tail of unused tools, and stood up a quarterly review process so the spend never re-bloats. The byproduct was a current map of every place organizational data was sitting outside the EHR.

Date
November 2025
Duration
10 weeks
Scope
Enterprise
Status
Completed

01 / The problem

Software spend had grown organically over years. Departments signed up for tools, used them for a quarter, lost the champion, and kept paying. Some subscriptions had no internal owner at all. Renewal notices were going to inboxes that no longer existed. Worse, every unmanaged subscription was an unmanaged data residency: PHI and operational data were sitting in tools no one had inventoried, let alone reviewed under HIPAA.

02 / The approach

  1. Pulled every SaaS sign-on through Entra ID and cross-referenced with corporate card and AP vendor data to build a definitive list of every active subscription
  2. Tagged each subscription with: business owner, last sign-in activity, license count versus active users, contract end date, PHI exposure tier, and renewal price
  3. Identified the obvious cuts first: zero-active-user subscriptions, duplicate tools serving the same purpose, and tools whose function had been absorbed into M365 or another existing platform
  4. Renegotiated the top ten contracts by spend with a written walk-away alternative for each, which moved actual price
  5. Where a tool had to stay but had PHI exposure, ran a vendor risk review and either tightened the integration or moved the data into a sanctioned location
  6. Stood up a quarterly SaaS review: every subscription has an owner, every owner reaffirms the need quarterly, and unowned subscriptions enter a thirty-day decommission window
  7. Wired the new-subscription request path through JSM with a security and finance gate before any card is charged

04 / What I learned

The savings number got the project funded. The PHI inventory was the actual win. Until the audit, no one in the building had a complete list of where organizational and patient data was sitting. After the audit, the BAA file matched the SaaS file matched the active sign-on file. The quarterly review is the only thing that keeps that picture true. Without it, the same drift will recur within eighteen months.
